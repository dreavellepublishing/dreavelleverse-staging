IMPORTANT LIMITATIONS:
- Manual admin review only; no automatic image analysis or notification feed.
- Admin-browser storage copy happens before approval RPC; these steps are not atomic.
- On failure, the browser attempts cleanup, but it can fail.
- The SQL checks paths and ownership, not image-byte identity.
- This is a trial workflow, not fully secure content moderation. Strong enforcement requires a trusted server-side approval process.
- Existing public covers are not retroactively moderated.
